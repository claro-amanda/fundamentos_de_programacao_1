# fundamentos_de_programacao_1
Listas de exercícios em linguagem C - Bacharelado em Sistemas de Informação - 1º período.

LISTAS DE EXERCÍCIOS:
AULA 3:
lista3_ex1: Compara o custo e rendimento do uso de álcool e gasolina em um carro bicombustível e determina qual combustível é mais econômico.
lista3_ex2: Recebe um número de três dígitos e o imprime invertido, eliminando possíveis zeros à esquerda.
lista3_ex3: Utiliza estruturas condicionais para identificar o maior entre três números inteiros.
lista3_ex4: Calcula a duração de um jogo a partir dos horários de início e fim, posteriormente, incluindo os minutos.
lista3_ex6: Determina o quadrante ou a posição de um ponto no plano cartesiano a partir de suas coordenadas.

AULA 4:
tarefa4_ex2: Verifica, utilizando operadores lógicos, se um número atende às condições estabelecidas para ser classificado como válido.
tarefa4_ex3: Calcula a idade e o tempo de contribuição de um empregado para determinar se ele pode se aposentar no ano atual.
lista4_ex1: Recebe três números distintos e os apresenta em ordem crescente sem modificar seus valores originais.
lista4_ex2: Calcula a idade de uma pessoa a partir de sua data de nascimento e da data atual.
lista4_ex3: Determina a pontuação de um lançamento de basquete com base na distância do robô até a cesta.
lista4_ex4: Calcula a menor quantidade de cédulas de Real necessária para representar um determinado valor.
lista4_ex5: Verifica se três valores podem formar um triângulo e classifica-o como isósceles, equilátero ou escaleno.
lista4_ex6: Calcula o dígito verificador de uma conta-corrente de três dígitos seguindo o algoritmo especificado.
